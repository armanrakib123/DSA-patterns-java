# Graph DFS (গ্রাফ ডিএফএস)

## Introduction
ট্রি-তে DFS করা সহজ কারণ সেখানে কোনো সাইকেল থাকে না। কিন্তু গ্রাফে DFS করা একটু বেশি চ্যালেঞ্জিং এবং শক্তিশালী। গ্রাফ ডিএফএস মূলত একটি নির্দিষ্ট নোড থেকে শুরু করে যতটা গভীরে যাওয়া সম্ভব ততটা গভীরে যায়।

## Connectivity (কানেক্টিভিটি)
গ্রাফ ডিএফএস মূলত চেক করতে ব্যবহৃত হয় যে দুটি নোডের মধ্যে কোনো রাস্তা আছে কি না। 
যদি গ্রাফটি ডিসকানেক্টেড (Disconnected) হয় (অর্থাৎ সব নোড একে অপরের সাথে যুক্ত না থাকে), তবে আমাদের সব নোড ভিজিট করার জন্য একটি লুপ চালাতে হয়।

```java
for (int i = 0; i < numNodes; i++) {
    if (!visited[i]) {
        dfs(i, visited);
        countComponents++; // এটি ডিসকানেক্টেড আইল্যান্ডের সংখ্যা গুণতে পারে
    }
}
```

## Applications of Graph DFS
১. **Cycle Detection:** গ্রাফে কোনো লুপ বা সাইকেল আছে কি না তা বের করা।
২. **Topological Sort:** টাস্ক শিডিউলিং-এর জন্য নোডগুলোকে একটি লিনিয়ার অর্ডারে সাজানো।
৩. **Connected Components:** একটি গ্রাফে কয়টি আলাদা আলাদা গ্রুপ আছে তা বের করা।
৪. **Path Finding:** সোর্স থেকে ডেস্টিনেশনে যাওয়ার রাস্তা খুঁজে বের করা।

## Stack Space & Deep Recursion
মনে রাখবেন, DFS রিকার্সিভলি কল হয়। যদি গ্রাফটি অনেক বড় হয় (চেইন লাইক গ্রাফ), তবে `java.lang.StackOverflowError` হতে পারে। 
Software Company ইন্টারভিউতে খুব বড় ডাটা সেট থাকলে অনেক সময় **Iterative DFS** (নিজে একটি স্ট্যাক অবজেক্ট ব্যবহার করে) করতে বলা হতে পারে।

গ্রাফ ডিএফএস আয়ত্ত করা মানে হলো আপনি প্রায় ৩০% মিডিয়াম-হার্ড লিটকোড প্রবলেম সলভ করার ক্ষমতা অর্জন করলেন। 🕸️🔍✅
