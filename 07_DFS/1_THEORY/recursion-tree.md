# Recursion Tree (রিকার্সন ট্রি)

## Introduction (ভূমিকা)
DFS (Depth-First Search) বোঝার প্রথম শর্ত হলো **Recursion** এবং **Recursion Tree** বোঝা। যখন একটি ফাংশন নিজেকে কল করে, তখন মেমরিতে একটি নির্দিষ্ট প্যাটার্ন তৈরি হয় যা দেখতে একটি উল্টানো গাছের (Tree) মতো। 

## What is a Recursion Tree?
একটি রিকার্সিভ ফাংশন কল হওয়ার পর সে যখন আবার নিজেকে কল করে, তখন আগের কলটি মেমরির **Stack**-এ ওয়েট করে। এই চেইন অফ কমান্ডটি যখন আমরা খাতায় ড্র করি, তখন তাকেই রিকার্সন ট্রি বলা হয়।

উদাহরণ: `Fibonacci(4)`
```text
           fib(4)
          /      \
      fib(3)     fib(2)
      /    \     /    \
   fib(2) fib(1) fib(1) fib(0)
   /    \
fib(1) fib(0)
```

## Key Components
১. **State:** প্রতিটি নোড একটি নির্দিষ্ট স্টেট বা প্যারামিটার ভ্যালু রিপ্রেজেন্ট করে।
২. **Branching Factor:** একটি ফাংশন তার ভেতরে কয়টি রিকার্সিভ কল করছে।
৩. **Depth:** ট্রি-টি কত গভীরে যাচ্ছে (এটিই স্ট্যাক স্পেস নির্ধারণ করে)।
৪. **Base Case:** যেখানে গিয়ে রিকার্সন থেমে যায় (লিফ নোড)।

## Complexity Analysis (ট্রি দেখে কমপ্লেক্সিটি নির্ণয়)
- **Time Complexity:** $O(Branching Factor^{Depth})$। উপরের ফিবোনাক্কি উদাহরণে প্রতিটি নোড থেকে ২টি কল হচ্ছে, তাই এর কমপ্লেক্সিটি $O(2^N)$।
- **Space Complexity:** $O(Depth)$। কারণ স্ট্যাক-এ এক সময়ে সর্বোচ্চ ট্রির হাইটের সমান ফাংশন কল জমা থাকে।
