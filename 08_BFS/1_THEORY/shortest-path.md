# Shortest Path using BFS (বিএফএস দিয়ে শর্টেস্ট পাথ)

## The Golden Rule (স্বর্ণালী নিয়ম)
যদি একটি গ্রাফের সব এজের (Edges) ওজন বা ওয়েট (Weight) সমান হয়, তবে **BFS সবসময় সবচেয়ে ছোট রাস্তা (Shortest Path) খুঁজে পায়।**

## Why not DFS?
DFS একটি রাস্তা ধরে একদম শেষ পর্যন্ত চলে যায়। সে হয়তো একটি রাস্তা খুঁজে পাবে, কিন্তু সেটি যে সবচেয়ে ছোট হবে তার কোনো গ্যারান্টি নেই। কিন্তু BFS যেহেতু পানির ঢেউয়ের মতো লেভেল-বাই-লেভেল চারদিকে ছড়ায়, তাই সে যখনই টার্গেট নোডটিকে খুঁজে পাবে, সেটিই হবে সবচেয়ে কম দূরত্বের রাস্তা।

## Steps to find Shortest Path
১. স্টার্টিং নোডটি কিউতে রাখুন এবং একটি `dist = 0` ভেরিয়েবল নিন।
২. লেভেল অর্ডার ট্রাভার্সাল শুরু করুন।
৩. প্রতিবার এক লেভেল শেষ হলে `dist++` করুন।
৪. যে মুহূর্তে টার্গেট নোডটি পাবেন, বর্তমান `dist` ভ্যালুটিই আপনার উত্তর।

## Mandatory Visited Set
গ্রাফের ক্ষেত্রে সাইকেল থাকতে পারে। তাই কোনো নোডকে কিউতে পুশ করার সময় অবশ্যই তাকে `visited` মার্ক করতে হবে। 
**Pro-tip:** নোড পপ করার সময় নয়, বরং **কিউতে ঢোকানোর (Push/Offer) সময়** ভিজিটেড মার্ক করুন। এটি মেমরি অনেক সেভ করে।

## BFS Shortest Path Complexity
- **Time:** $O(V + E)$
- **Space:** $O(V)$
