# String Matching DP (স্ট্রিং ম্যাচিং ডিপি)

## The Core Concept
দুটি স্ট্রিংয়ের মধ্যে সিমিলারিটি বা রিলেশন বের করার জন্য ২ডি ডিপি একটি অত্যন্ত শক্তিশালী পদ্ধতি। এখানে টেবিলের প্রতিটি সেল `dp[i][j]` নির্দেশ করে প্রথম স্ট্রিংয়ের $i$ তম এবং দ্বিতীয় স্ট্রিংয়ের $j$ তম অক্ষর পর্যন্ত সাব-প্রবলেমের রেজাল্ট।

## 1. Longest Common Subsequence (LCS)
যদি স্ট্রিং দুটির $i$ এবং $j$ ইনডেক্সের ক্যারেক্টার মিলে যায়:
`dp[i][j] = 1 + dp[i-1][j-1]`
যদি না মিলে:
`dp[i][j] = max(dp[i-1][j], dp[i][j-1])`

## 2. Edit Distance
একটি স্ট্রিংকে অন্যটিতে কনভার্ট করতে সর্বনিম্ন কয়টি অপারেশন (Insert, Delete, Replace) লাগবে।
যদি মিলে যায়: কোনো খরচ নেই, `dp[i-1][j-1]`।
যদি না মিলে: `1 + min(insert, delete, replace)`।

## Why it is important?
ইন্টারভিউতে স্ট্রিং ম্যাচিং প্রবলেমগুলো খুব ফ্রিকোয়েন্টলি আসে। বিশেষ করে **LCS** প্যাটার্নটি জানা থাকলে আপনি Longest Palindromic Subsequence বা Shortest Common Supersequence-এর মতো প্রবলেমগুলো চোখের পলকে সলভ করতে পারবেন।
