# 2D Prefix Sum (টু-ডাইমেনশনাল প্রিফিক্স সাম)

## Concept (ধারণা)
1D Array এর মতো, একটি 2D Matrix বা গ্রিডের ক্ষেত্রেও আমরা Prefix Sum ব্যবহার করতে পারি।
`P[i][j]` হবে `(0,0)` থেকে `(i,j)` পর্যন্ত সাব-ম্যাট্রিক্সের (Sub-matrix) সব উপাদানের যোগফল।

## Building the 2D Prefix Sum Matrix (কীভাবে তৈরি করব?)
ধরা যাক মূল ম্যাট্রিক্স হলো `M` এবং প্রিফিক্স ম্যাট্রিক্স হলো `P`।
`P[i][j]` বের করতে হলে আমাদের ৪টি বিষয় খেয়াল করতে হবে:
1. বর্তমান এলিমেন্ট: `M[i][j]`
2. ওপরের অংশের যোগফল: `P[i-1][j]`
3. বাঁ দিকের অংশের যোগফল: `P[i][j-1]`
4. **ওপরের-বাঁ দিকের অংশ (Overlapping area) যা দুবার যোগ হয়ে গেছে, সেটি বিয়োগ করতে হবে**: `P[i-1][j-1]`

সূত্র:
`P[i][j] = M[i][j] + P[i-1][j] + P[i][j-1] - P[i-1][j-1]`

### 1-Based Indexing
1D এর মতোই 2D তেও বাউন্ডারি কন্ডিশন (Index Out of Bounds) এড়াতে আমরা ম্যাট্রিক্সের সাইজ `(row+1) x (col+1)` নিই।
সূত্রটি দাঁড়াবে:
`P[i][j] = M[i-1][j-1] + P[i-1][j] + P[i][j-1] - P[i-1][j-1]` (যেখানে $i \ge 1, j \ge 1$)

## Range Query in 2D (রেঞ্জ কুয়েরি)
যদি আপনাকে বলা হয় `(r1, c1)` থেকে `(r2, c2)` পর্যন্ত সাব-ম্যাট্রিক্সের যোগফল বের করতে, তখন সাধারণ নিয়মে লুপ চালালে $O(R \times C)$ সময় লাগবে। কিন্তু 2D Prefix Sum দিয়ে এটি $O(1)$ টাইমে করা যায়।

সূত্র:
`Sum = P[r2][c2] - P[r1-1][c2] - P[r2][c1-1] + P[r1-1][c1-1]`

**ব্যাখ্যা**:
1. পুরো বড় রেক্ট্যাঙ্গেল `P[r2][c2]` নিই।
2. ওপরের অপ্রয়োজনীয় অংশ `P[r1-1][c2]` বিয়োগ করি।
3. বাঁ দিকের অপ্রয়োজনীয় অংশ `P[r2][c1-1]` বিয়োগ করি।
4. ওপরের-বাঁ দিকের অংশটা আমরা দুইবার বিয়োগ করেছি, তাই একবার যোগ করে দিই `+ P[r1-1][c1-1]`।

*(নোট: 1-based indexing ব্যবহার করলে `r1, c1` ইত্যাদির মানগুলো সেই অনুযায়ী অ্যাডজাস্ট করে নিতে হয়।)*

## Importance in Software Company (ইন্টারভিউতে এর গুরুত্ব)
2D Prefix Sum সচরাচর সরাসরি আসে না, তবে ইমেজ প্রসেসিং (Image Processing), গ্রিড অপ্টিমাইজেশন (Matrix Block Sum), এবং "Max Sum of Rectangle No Larger Than K" এর মতো হার্ড (Hard) প্রবলেমে এটি অপরিহার্য। এটি গ্রাফিক্স এবং কম্পিউটার ভিশনের অনেক বেসিক অ্যালগরিদমের মূল ভিত্তি (Integral Image)।
