# Path Compression & Union by Rank (অপ্টিমাইজেশন টেকনিক)

DSU-কে সুপারফাস্ট করার জন্য দুটি শক্তিশালী অপ্টিমাইজেশন ব্যবহার করা হয়।

## 1. Path Compression (পাথ কমপ্রেশন)
রিকার্সিভলি `find` করার সময় আমরা যখন রুট নোডটি পেয়ে যাই, তখন পথের সব নোডকে সরাসরি ওই রুটের সাথে যুক্ত করে দেই। 
- **সুবিধা:** পরবর্তীবার ওই সেটের যেকোনো নোডের রুট খুঁজতে গেলে মাত্র এক ধাপেই তা পাওয়া যায়। ট্রি-টির উচ্চতা (Height) অনেক কমে যায়।

```java
int find(int i) {
    if (parent[i] == i) return i;
    return parent[i] = find(parent[i]); // এটাই হলো ম্যাজিক লাইন!
}
```

## 2. Union by Rank / Size
ইউনিয়ন করার সময় আমরা সবসময় ছোট ট্রি-টিকে বড় ট্রি-র নিচে যুক্ত করি। 
- **Rank:** ট্রির উচ্চতা বা গভীরতা নির্দেশ করে।
- **Size:** ট্রিতে মোট কতগুলো নোড আছে তা নির্দেশ করে।
- **সুবিধা:** এটি ট্রি-টিকে স্কিউড (Skewed) বা লম্বা হতে দেয় না, ফলে ট্রি ব্যালেন্সড থাকে।

## Time Complexity: Inverse Ackermann Function
এই দুটি অপ্টিমাইজেশন একসাথে ব্যবহার করলে DSU-এর টাইম কমপ্লেক্সিটি হয় $O(\alpha(N))$। এই $\alpha(N)$ ফাংশনটি এতই ধীরে বাড়ে যে ১০^৬০ পর্যন্ত ডাটার জন্যও এর ভ্যালু ৫-এর নিচে থাকে। তাই আমরা একে প্রায় **O(1)** বা Constant টাইম বলতে পারি।
