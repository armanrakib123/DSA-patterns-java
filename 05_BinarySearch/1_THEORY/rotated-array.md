# Binary Search in Rotated Array (রোটেটেড অ্যারে)

## The Concept (লজিক)
"Search in Rotated Sorted Array" (LeetCode 33) হলো বাইনারি সার্চের সবচেয়ে জনপ্রিয় মিডিয়াম/হার্ড লেভেলের প্রবলেম।
আপনাকে একটি সর্টেড অ্যারে দেওয়া হবে যাকে যেকোনো একটি পজিশনে রোটেট (Rotate) বা ঘোরানো হয়েছে।
যেমন: `[0, 1, 2, 4, 5, 6, 7]` কে রোটেট করলে হতে পারে `[4, 5, 6, 7, 0, 1, 2]`।
এখানে সরাসরি সাধারণ বাইনারি সার্চ কাজ করবে না।

## The "One Half is Always Sorted" Trick
এই সমস্যার মূল চাবিকাঠি হলো একটি গাণিতিক সত্য: 
**রোটেটেড অ্যারের যেকোনো `mid` পয়েন্ট নিলে, হয় তার বাম পাশ পুরোপুরি সর্টেড থাকবে, নাহয় তার ডান পাশ পুরোপুরি সর্টেড থাকবে।**

১. আমরা `mid` বের করব।
২. চেক করব বাম পাশ `[left ... mid]` সর্টেড কি না। (শর্ত: `nums[left] <= nums[mid]`)
   - যদি বাম পাশ সর্টেড হয়, তবে আমরা খুব সহজেই চেক করতে পারি টার্গেটটি কি এই বাম পাশের রেঞ্জের ভেতরে আছে নাকি নেই।
   - যদি থাকে, তবে `right = mid - 1`।
   - যদি না থাকে, তবে টার্গেটটি ডান পাশেই থাকতে হবে, তাই `left = mid + 1`।
৩. যদি বাম পাশ সর্টেড না হয়, তার মানে ডান পাশ `[mid ... right]` অবশ্যই সর্টেড।
   - তখন আমরা চেক করব টার্গেটটি কি ডান পাশের রেঞ্জের ভেতরে আছে কি না।
   - যদি থাকে, তবে `left = mid + 1`।
   - যদি না থাকে, তবে `right = mid - 1`।

## Visual Example
Array: `[4, 5, 6, 7, 0, 1, 2]`, Target: `0`
- `left = 0, right = 6, mid = 3 (value 7)`
- বাম পাশ `[4, 5, 6, 7]` সর্টেড। (`nums[left] <= nums[mid]`)
- টার্গেট `0` কি ৪ থেকে ৭ এর ভেতরে আছে? না।
- তার মানে টার্গেটটি ডান পাশেই আছে।
- `left = mid + 1 = 4`।
- এখন Search Space হলো `[0, 1, 2]`। এবার সাধারণ বাইনারি সার্চের মতোই কাজ হবে।

## Find Minimum in Rotated Sorted Array (সর্বনিম্ন সংখ্যা খোঁজা)
আরেকটি ক্লাসিক প্রবলেম হলো (LeetCode 153), রোটেটেড অ্যারে থেকে সবচেয়ে ছোট সংখ্যাটি বের করা।
এখানে টার্গেট খোঁজার ব্যাপার নেই, শুধু "অ্যানোমালি" বা অস্বাভাবিক পয়েন্টটি খুঁজতে হবে।
লজিক:
- যদি `nums[mid] > nums[right]` হয়, তার মানে ছোট সংখ্যাটি অবশ্যই ডানদিকে আছে (কারণ সাধারণ নিয়মে ডানদিকে বড় সংখ্যা থাকার কথা)। তাই `left = mid + 1`।
- নতুবা (যদি `nums[mid] <= nums[right]`), তার মানে ডানদিকটি একদম ঠিক আছে (সর্টেড), তাই ছোট সংখ্যাটি বামদিকেই থাকতে হবে (বা `mid` নিজেই হতে পারে)। তাই `right = mid`।

এই দুটো প্রবলেম ভালোভাবে বুঝলে বাইনারি সার্চের যেকোনো মডিফায়েড ভার্সন (Modified Version) আপনার কাছে সহজ হয়ে যাবে।
